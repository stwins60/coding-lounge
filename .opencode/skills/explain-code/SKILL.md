# Explain Code

## Steps

1. Read the smallest relevant code section.
2. State its overall job in one sentence.
3. Walk through the important lines in execution order.
4. Define new terms using familiar words and one concrete example.
5. Point out how values change as the code runs.
6. Ask one short question that lets the learner check their understanding.

## Style

- Use short sentences and concrete examples.
- Explain one idea at a time.
- Do not rewrite the code unless asked.
- Do not pretend an uncertain interpretation is a fact; run or inspect the code when possible.
