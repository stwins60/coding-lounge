# README Writer

## Steps

1. Inspect the actual files, dependencies, and runnable commands.
2. Identify the reader and the first task they need to complete.
3. Put prerequisites and setup before usage.
4. Use commands that match the supported operating systems.
5. Add one minimal example with the expected result.
6. Link to deeper documentation instead of duplicating it.
7. Verify commands when the environment allows it.

Never invent commands, features, or successful output. Keep headings and paragraphs easy to scan.
