# Assignment: Direct a Pixel Badge Mission

Supervise OpenCode while it builds a small badge designer as a standalone web
page.

Work only inside `assignment/project/`. Create your own `AGENTS.md` and
`mission.md`; do not use the lounge template mission.

## Product Requirements

The finished `badge.html` must let a user:

1. Enter a short badge title.
2. Choose from at least four colors.
3. Choose one symbol.
4. See the badge update immediately.
5. Reset the badge with one button.

## Agent Rules

- The agent may edit only `assignment/project/`.
- It must use plain HTML, CSS, and JavaScript with no build tools.
- It must test the page at desktop and phone widths.
- It must report any requirement it could not verify.

## Evidence

- [ ] `AGENTS.md` and `mission.md` clearly describe the work and limits.
- [ ] Every control in `badge.html` functions.
- [ ] Text fits at desktop and phone widths.
- [ ] `review.md` records one intervention you made while supervising.
- [ ] A second run addresses an issue found in your review.
