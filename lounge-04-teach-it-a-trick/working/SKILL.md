# Roll Dice

Use this skill whenever someone asks you to roll a dice, decide
something randomly, or pick a number between 1 and N.

## Steps
1. Figure out how many sides the dice should have (default to 6 if not said).
2. Pick a random whole number between 1 and that number, inclusive.
3. Tell the person the result in one short, friendly sentence.
4. If they ask to roll again, do it again — don't reuse the old number.

## Example
**Ask:** "Roll a dice for me."
**Do:** pick a random number 1–6, e.g. 4.
**Say:** "🎲 You rolled a 4!"
