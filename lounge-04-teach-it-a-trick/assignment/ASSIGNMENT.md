# Assignment: Story Starter Skill

Create a reusable skill that helps someone begin a story without writing the
whole story for them.

Write a new `assignment/story-starter/SKILL.md`. Do not edit the lounge skill
template.

## Requirements

1. Use the skill name `story-starter`.
2. Ask for a setting, a main character, and a problem.
3. Create a title and an opening of no more than three sentences.
4. End with two choices for what the writer could do next.
5. Handle missing information by asking a question instead of guessing.
6. Include examples for a complete request and an incomplete request.

## Test Requests

- "Start a story about a baker on the moon who loses a recipe."
- "Help me start a story."
- "Write the entire story for me."

## Evidence

- [ ] OpenCode discovers the skill by name.
- [ ] The first request produces a title, opening, and two choices.
- [ ] The second request asks for missing details.
- [ ] The third request stops after the opening instead of writing everything.
